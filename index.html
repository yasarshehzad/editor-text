Welcome to Editor Text

Editor Text is a free app that allows you to create, open, and edit text files on your computer and Google Drive.

📖 How to use Editor Text

  • Select a text file from your computer, Google Drive, or GMail attachment.
  • The file will be displayed in your browser where you can then make changes.
  • After edits are made, save back to Google Drive using the cloud sync toolbar button.
  • Download a copy of the file to your computer using the "Download" button.

⚙️ How Editor Text works

  • Pure Javascript web app: all processing is done 100% locally in your browser.
  • Can open all text file types including TXT, CSV, HTML, XML, CSS, JSON, C++, Java, and Python.
  • Premium features: syntax styling helper, word wrap modes, print margins, and themes.
  • Complete keyboard shortcuts supported via the keyboard toolbar menu.

About Editor Text

Editor Text is a free, modern online text editor and document creation tool built for speed, privacy, and simplicity. You can create, open, edit, format, and download text files directly in your web browser. There is no need to install heavy software, and your files never leave your device unless you choose to save them to the cloud.

Our rich text editor includes advanced features such as real-time word counting, reading time analytics, seamless HTML live previews, and customizable text wrap controls. Whether you're drafting a quick note, writing code, or formatting a document, Editor Text provides a clean, flat, unobtrusive interface to keep your focus exactly where it belongs: on your text.
