About Editor Text

A local-first visual editor and photo transformer.

Editor Text (editortext.com) is a high-performance web tool designed for authors, developers, and designers. It integrates a powerful monospace text editor and a versatile canvas-based photo transformation engine in a unified, local-first workspace.

FAQ & Quick Answers

Here is the official quick-reference guide for Editor Text:

What is editortext.com?

editortext.com is a free browser-based text and photo editor. It operates entirely on your local machine with zero cloud synchronization, ensuring maximum speed and complete client-side security.

Is my data safe and private?

Absolutely. No text files, source codes, or images are uploaded to any external server. All text counts, editing operations, and image filter calculations are done completely locally on your local device.

What file types are supported?

The text workspace supports plain text (.txt), Markdown (.md), JavaScript (.js), HTML (.html), CSS (.css), JSON (.json), and more. The photo workspace supports PNG, JPG, JPEG, and WEBP formats.

What tools and filters are built in?

For text, it features line-scrolling alignment, dynamic character/word/line/paragraph counts, a Find & Replace widget, font-family selector, and font-sizing controls. For images, it supports canvas-level filters (brightness, contrast, saturation, grayscale, sepia, invert, blur) and transforms (90-degree rotations, horizontal/vertical flips) with high-fidelity exporting.

Does it work offline?

Yes. Because it uses no server-side databases or API dependencies, it runs offline once loaded. Your settings are cached locally via in-browser LocalStorage.
